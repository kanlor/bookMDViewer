# KanlorOne MDLens

**简体中文** | [English](README.en.md)

> 不停打磨 · 侧重阅读的 MarkDown 轻量超级助手

一款**轻量、完全本地化**的 Markdown 查看器与简单编辑器，以 **Tauri v2** 打造，使用操作系统内建的 WebView（Windows 用 WebView2、macOS 用 WKWebView、Linux 用 WebKitGTK），而非内嵌整个 Chromium。

双击任意 `.md` 文件即可瞬间开启、漂亮渲染 —— 内建可导航的章节大纲、代码语法高亮、Mermaid 图表、KaTeX 公式、可即时预览的实时编辑，以及多种一键导出。没有云端、没有遥测，全部离线运行。

## 阅读模式 —— 大纲 + 渲染后的 Markdown

左侧的\*\*章节大纲(TOC)\*\*会根据文件标题自动产生；点击任一项即可跳转，并会高亮你目前正在阅读的章节。

按工具栏「实时」切换（或 `Ctrl+E`）进入所见即所得的实时编辑，预览随输入即时更新，`Ctrl+S` 存回磁盘。

# 功能特色

* **三种显示模式** —— 阅读 / 实时(所见即所得) / 源码，循环切换；切换时以切换前顶部内容为锚点，精准对应、不跳转

* **GFM 渲染** —— 表格、任务清单、删除线（`markdown-it`）

* **脚注渲染** —— `[^1]` 语法正确渲染上标引用与底部定义区，双向点击跳转并高亮

* **公式渲染** —— 基于 KaTeX（离线可用），支持行内 `$…$` 与块级 `$$…$$`，实时模式下点击公式即可编辑并实时预览

* **`==高亮==`** —— 渲染为黄色荧光标记，明暗主题自动适配

* **代码语法高亮**（`highlight.js`）

* **代码文件只读打开**（可选）—— 设置开启后可直接以语法高亮代码块打开 `.py/.js/.ts/.java/.c/.cpp/.go/.rs/.sql/.json/.yaml/.html/.css/.sh` 等

* **表格实时编辑** —— 阅读 / 实时模式下整行整列悬停高亮、增删行列、上移下移、左右移动、合并拆分、角落聚合菜单与边界插入条

* **Mermaid 图表** —— 按需加载，仅当文件实际含有 ` ```mermaid ` 区块时才加载

* **语义内容上色**（需注册）—— 对白、数字、英文、自定义词库分类着色，可一键开关

* **大纲 / TOC 侧栏** —— 根据标题自动建立、滚动时高亮当前章节、`Ctrl+\` 折叠

* **多标签页** —— 同时打开多个文档，标签管理与切换

* **查找与替换** —— `Ctrl+F`，全部匹配高亮 + 当前项强调、N/M 计数、单个/全部替换

* **导出** —— HTML、Word(DOCX)、PDF 免费导出；长图(PNG)、图片/表格/代码/链接附件需注册；同步保留公式、脚注、本地图片

* **本机相对路径图片** —— 文件中 `![](images/x.png)`、Windows 盘符绝对路径均正确显示

* **多编码兼容** —— 自动识别 UTF-8 / GBK / Big5 / Shift\_JIS / EUC-KR 等

* **文件浏览器**（`Ctrl+B`）—— 目录浏览、路径栏跳转、「仅MD/TXT」筛选、最近打开（可清空）、切换目录

* **撤销 / 恢复** —— 最多 10 步向前与向后，覆盖所有编辑入口

* **底部状态栏** —— 文件路径、编码、章节数、内容统计、文件属性

* **安全** —— 渲染后 HTML 经 DOMPurify 清理并套用严格 CSP，打开不可信文件也不执行恶意脚本

* 深色 / 浅色主题跟随系统设定；外部链接以默认浏览器打开

* **在线检查更新** —— 「关于 → 更新」自动比对最新版本，发现新版可应用内一键下载

## 为什么很多杀毒软件会误报（Windows）

本软件为个人开源作品，exe **尚未经过代码签名（code signing）**，Windows Defender 或 SmartScreen 偶尔会把它误判为 `Program:Win32/Wacapew.A!ml` 之类的「潜在不需要的程序（PUA）」。这是**误报**而非恶意程序 —— 名称中的 `!ml` 代表机器学习*推测性*判断，而非病毒特征码比对。

* 建议优先下载「安装版」，误报几率通常更低

* 可在通知中按「允许 / 还原」，或到 **Windows 安全中心 → 病毒与威胁防护 → 保护历史记录** 还原

| ----------------------- | ------------- |
| `Ctrl+O`                | 打开文件          |
| `Ctrl+S`                | 保存            |

| `Ctrl+\`                | 切换大纲侧栏        |

| `Esc`                   | 关闭弹窗          |

# 启动参数

```bash
KanlorOne_MDLens.exe file.md            # 打开并渲染
KanlorOne_MDLens.exe file.md --edit     # 直接进入实时编辑模式
KanlorOne_MDLens.exe file.md --zoom=1.5 # 整体 UI 放大（高 DPI / 无障碍）
```

# 开发

```bash
npm install

```

```bash

```

# 一键发布到 Gitee

运行 **「发布到Gitee.bat」** 即可自动完成：构建打包 → 推送 README 到仓库 → 创建/更新 Release（Tag 为当前版本号，如 `v1.7.3`）→ 把 `README.md` 中最新的更新说明作为 Release 更新内容 → 上传 Windows 安装包。

* **用户可见更新**：Gitee 仓库首页 README 展示更新历史；应用内「关于 → 更新」读取 Release 的更新说明并提示，由用户选择是否下载

* **需要私人令牌**：在 Gitee 申请「私人令牌」(`personal_access_token`)，设为环境变量 `GITEE_TOKEN`，或在仓库根创建 `.gitee_token` 文件存放（不要提交该文件）

* 发布前请先在 `README.md` 末尾「更新日志」的顶部新增本次 `### Vx.x.x` 条目
